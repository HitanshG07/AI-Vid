## 5. One-Click PowerShell Script to Download All 18 Reference Videos Locally

To save the actual `.mp4` files and extracted reference frames into `C:\AI-Vid\ref_pack\` on your Windows 11 laptop:

```powershell
# Run in PowerShell at C:\AI-Vid
mkdir C:\AI-Vid\ref_pack\videos, C:\AI-Vid\ref_pack\frames -Force

# 1. YouTube Shorts, Compilations & Tutorials (Zero login required)
$yt_urls = @(
  "https://www.youtube.com/shorts/47J1l3p1Abc",
  "https://www.youtube.com/watch?v=EDgSEw9ZJq0",
  "https://www.youtube.com/watch?v=E_wO8RhmUpc",
  "https://www.youtube.com/watch?v=IJT0jXZidkY",
  "https://www.youtube.com/watch?v=4qHsyNVE-3U",
  "https://www.youtube.com/watch?v=n_1hAIHUawE"
)

foreach ($u in $yt_urls) {
  yt-dlp -f "bv*+ba/b" --merge-output-format mp4 -o "C:/AI-Vid/ref_pack/videos/%(extractor)s_%(id)s.%(ext)s" $u
}

# 2. Instagram Reels (Try direct yt-dlp first; if Instagram rate-limits your IP without login, paste the URL into https://cobalt.tools and save into C:\AI-Vid\ref_pack\videos\)
$ig_urls = @(

  "https://www.instagram.com/reel/DfvPMO-BQIW/",

  "https://www.instagram.com/reel/Dfnt07lhqoI/"
)

foreach ($u in $ig_urls) {
  yt-dlp -f "bv*+ba/b" --merge-output-format mp4 -o "C:/AI-Vid/ref_pack/videos/%(extractor)s_%(id)s.%(ext)s" $u

# 3. Extract 1 frame every 2 seconds from all downloaded MP4s for visual study
Get-ChildItem C:\AI-Vid\ref_pack\videos\*.mp4 | ForEach-Object {
  $out = "C:\AI-Vid\ref_pack\frames\$($_.BaseName)"
  mkdir $out -Force | Out-Null
  ffmpeg -i $_.FullName -vf "fps=0.5" "$out\frame_%04d.png"
}
```
